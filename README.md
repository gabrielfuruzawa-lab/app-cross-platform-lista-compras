## Descrição
Aplicação móvel e web desenvolvida com React Native e Expo para o CheckPoint 2, explorando imutabilidade de estado com o hook `useState` e renderização em lista otimizada com `FlatList`.

## Como executar
1. Instale as dependências:
   ```bash
   npm install
   ``` 
2. Inicie o projeto com o Expo:
   ```bash
   npx expo start
   ```
